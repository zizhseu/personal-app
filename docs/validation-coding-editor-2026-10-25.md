## 自动保存追加验证

运行 `node --test tests/coding-autosave.test.mjs`，7 项行为测试通过；完整 `npm run build` 通过。测试覆盖停止输入 1 秒防抖、慢请求期间的后续修改、离开时立即补存、失败重试、必填项、多个立即保存请求合并和卸载时取消定时保存。

独立示例库中使用实际页面输入事件和接口核验：

| 场景 | 结果 |
| --- | --- |
| 修改后 600 毫秒及停止输入 1 秒后检查 | 前者尚未写入，后者自动写入；页面没有「保存题目」和「还原」按钮，也没有成功弹窗 |
| 首次保存响应延迟 2 秒，再次输入 | 保存期间字段和编辑器未锁定，旧响应未覆盖新输入，最终写入最新内容 |
| 后端注入一次 503 | 顶部显示失败，当前输入保留，没有重复错误弹窗，约 3 秒后重试成功 |
| 输入后立刻返回列表 | 立即保存后才离开，没有弹出放弃修改确认框 |
| 新建题目首次保存延迟 2 秒，期间继续输入 | 只新增一条记录，跳转到对应题目地址，后续修改保存到同一记录，编辑器保留最新输入 |

验证使用忽略的 `.runtime/verify_coding_autosave.py` 模拟慢响应及一次性失败，不包含正式环境测试开关，未写入正式题库。首次新建请求未获成功确认时，不自动反复发创建请求；保留输入并允许手动重试。

## 边界

- JS / TS 使用 Monaco 内置语言服务。其他内置语言提供高亮、关键词、片段及当前文档中的词补全，不包含 Python / Java / C++ 语言服务器或项目级语义分析。
- 不执行用户代码，不提供在线判题或 AI 补全。停止输入 1 秒后自动保存，未填写题目名称或内容未通过校验时显示提示，不写入无效数据。
- 构建存在编辑器及语言服务分块体积提示；相关资源只在进入代码题工作区后加载，JS / TS Worker 在对应语言服务需要时启动。
