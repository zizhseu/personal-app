## 实测中修复的问题

- Windows Uvicorn reload 所用事件循环不支持异步子进程：改用 `Popen` 加后台线程等待，保留超时及取消清理。
- 首次安装不能依赖尚未安装的 pywin32：进程容器使用 Windows 标准库接口，未登录验证进程运行成功。
- GitHub releases 公共 API 限流：改用已核对 SHA256 的官方固定发布资产；不改变平台登录或验证流程。
