# 大模型设置验证记录（2026-10-19）

## 验证环境与范围

Windows，使用项目专用 `personal-app` conda 环境；前端执行完整类型检查与生产构建。单元测试使用临时目录、内存数据库和模拟 HTTP 上游，不调用外部模型、不使用真实账号或密钥。

结果：后端 58 项测试通过；前端完整类型检查与生产构建通过。

浏览器使用独立示例数据库和本机模拟服务验证。OAuth 身份由验证服务生成的独立 RSA 密钥签名，真实经过本机回调、JWT 验证与账号存储路径；模型回复与账号模型目录均为模拟。没有验证真实 ChatGPT 账号的开放资格、套餐额度或真实模型效果。

## 后端覆盖

- 默认环境配置、保存后即时读取、留空保留、替换、清除及不恢复旧环境密钥。
- 更换供应商、地址或 API 前缀后不继承旧密钥；Base URL 规范化与非法地址拒绝。
- 私有配置原子写入、Windows DPAPI 往返及写入失败保留旧配置。
- 设置读取和校验错误不返回原始 Key；拒绝外站来源、非本机 Host 和跨站访问。
- 连接测试只使用当前草稿与固定文字，不保存配置；API 与 ChatGPT 模型目录分别解析。
- Chat Completions 和 Responses 调用，动态切换、免密钥模式、上游错误安全提示及总超时。
- Responses 请求关闭存储、使用流式接口、将 system 上下文转换为 developer，并要求明确完成事件；流中断不提交部分回答。
- OAuth PKCE、state、nonce、首次颁发的 client_id、回调地址一致性、签名、issuer、audience、过期时间、授权范围、身份一致性、单次完成、取消及超时。
- 账号令牌续期串行化和旋转、失效后的重新授权、退出失败时清理本机令牌并保留注册映射。
- 既有简历面试、复盘、选择题解析、数据库迁移和待办回归。

## 浏览器检查

- 自定义服务 → 填写合成 Key → 获取模型列表 → 测试连接 → 保存 → 刷新；表单未保存时当前模型不变，保存后状态立即更新。
- 保存后密码框为空；再次空白保存保留密钥；清除后立即显示未就绪。localStorage 未写入合成 Key。
- 模拟 ChatGPT 登录经过本机回调后显示套餐授权与首次用量说明；模型选择、Responses 连接测试和保存成功。授权完成前后的 API 配置保持原样，显式保存后才切换模式。
- 退出后连接不再就绪；再次发起登录、取消登录的页面状态恢复正常。
- 390 CSS 像素手机视口及 1920、2560 CSS 像素桌面视口，无横向溢出；2560 下卡片宽 2272，右边距 28，保持随可用宽度展开。
- 未调用截图工具。通过 DOM、无障碍树、计算样式、页面交互与 API 状态核对。

## 复现

从 `backend` 目录，在项目专用 conda 环境运行 `python -m unittest discover -s tests -v`；从 `frontend` 目录运行 `npm run build`。正常启动见 README；真实账号接入需要由用户亲自授权，再使用设置页连接测试确认可用性。
